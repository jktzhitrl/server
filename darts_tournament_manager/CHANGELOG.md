# Changelog

## 0.1.0

Erste Version – Phasen 1–6 als lauffähiger, getesteter Code:

* **Phase 1** Grundsystem: Flutter-Projekt (Android, iOS, Web, Windows, macOS, Linux), responsive Navigation,
  dunkles Design, Firebase-Anbindung (Auth, Firestore) mit Demo-Fallback, Rollenverwaltung.
* **Phase 2** Spielverwaltung: 301/501/701/1001, Legs und Sätze, Eingabe pro Dart (Scheibe/Tasten) und per Summe,
  Live-Scoreboard, TV-Modus.
* **Phase 3** Checkout-System: regelbasierter Rechner, Varianten, Double-/Master-/Single-Out-Validierung,
  Checkout-Statistiken.
* **Phase 4** Turniere: Anmeldung, Auslosung (prüfen/tauschen/veröffentlichen), Gruppenphase, K.-o., Turnierbaum,
  automatischer Rundenfortschritt.
* **Phase 5** Statistiken und Spielerportal: Profile, Ranglisten, Historie, Live-Statistiken.
* **Phase 6** Double Elimination, Schweizer System, Cricket, Around the Clock, Training, TV-Modus, QR-Einladung.
* Security Rules (Emulator-getestet), Cloud Function mit Regel-Port (Paritätstests), GitHub-Actions-Workflows.
